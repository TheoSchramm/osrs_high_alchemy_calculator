# OSRS High Alchemy Calculator

Work out High Level Alchemy profit, experience and time using live Grand
Exchange prices.

**[Open the calculator](https://theoschramm.github.io/osrs_high_alchemy_calculator/)**

![The calculator, showing a few items and their profit](docs/screenshot.png)

## Running it locally

```bash
npm install        # only needed for the tests
npm run serve      # http://localhost:4173
npm test
```

Architecture, testing and design notes are in [docs/DEVELOPING.md](docs/DEVELOPING.md).
